# Minas del Valle

Juego publicado de prueba para la eval "se pierden datos" del orquestador. Los jugadores cuentan que a veces vuelven y tienen 0 monedas, y que una compra les dio la bolsa dos veces. Los perfiles guardados en el DataStore `Minas`, con claves `Player_<UserId>`, tienen la forma `{ coins, pickaxe }`.
